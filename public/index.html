What to export
This file can log someone into these accounts as you — no password, no 2FA, nothing else needed.

Cookies are live session keys and localStorage can hold auth tokens. Anyone who gets this file can open it in their own browser and be signed in as you on every site it covers, for as long as those sessions last. Changing your password afterwards does not undo it — only signing out / revoking sessions on each site does.

Never attach this to an email, upload it anywhere, send it over chat, or hand it to "support", a colleague, or anyone else. If you need to share browser data with someone, do it a different way (invite them to the account, share a password via a password manager, and so on). Delete this file once you're done with it.

Calculating…
This is your entire browsing identity in a file. Whoever extracts it on their own machine can run a browser that IS you — logged into every account, no password or 2FA prompt.

Cookies and saved passwords are encrypted with a key tied to your OS user account, so this exact copy only decrypts on this computer, signed in as you. It is not anonymized or scoped — it is a full copy of the profile, including every site you're logged into, autofill, and extensions data.

Do not send this file to anyone, upload it to cloud storage you don't fully control, or leave it lying around. If this machine or account is shared, or if you're building this for a client or teammate, you are responsible for how that copy of their identity gets used once you hand it over. Delete the zip and the extracted folder as soon as you're done debugging.
